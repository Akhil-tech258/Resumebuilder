[![Live Demo](https://img.shields.io/badge/Live%20Demo-GitHub%20Pages-6366f1?style=for-the-badge&logo=github)](https://akhil-tech258.github.io/Resumebuilder/)

> 🚀 **Live Demo:** [https://akhil-tech258.github.io/Resumebuilder/](https://akhil-tech258.github.io/Resumebuilder/)

A modern, responsive web application for creating clean, ATS-compliant resumes with real-time live preview, professional typography templates, and 1-click PDF download.

---

## 🌟 Key Features
- **⚡ Real-Time Split Preview:** Live updating preview as you type contact details, summary, experience, education, skills, and projects.
- **📱 Fully Responsive Mobile Layout:** Adaptive mobile mode featuring a segmented tab bar to switch between the Editor Form and Live Resume Preview on smaller screens.
- **📄 Multiple ATS-Friendly Templates:** Modern, Executive, Creative, and Minimalist templates with customizable accent colors and fonts.
- **📥 Direct PDF Export:** High-fidelity PDF rendering via `html2pdf.js` with preserved margins and vector typography.
- **💾 Local & Cloud Persistence:** Keeps resume data saved locally in `localStorage` so work is never lost on refresh.
- **🎨 Dark & Light Modes:** Sleek UI built with glassmorphism design tokens.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (CSS Grid, Flexbox, Custom Responsive Media Queries)
- **Scripting:** Vanilla JavaScript (Form state manager, real-time template renderer, PDF generator)
- **Libraries:** `html2pdf.js`, Font Awesome 6
- **Hosting:** GitHub Pages
